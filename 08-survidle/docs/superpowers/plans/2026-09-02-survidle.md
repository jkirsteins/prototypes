# Survidle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A playable, permadeath, offline-progressing northern survival idle game at `08-survidle`, every mechanic reachable from the UI.

**Architecture:** A pure, deterministic simulation (`src/sim/*`) over a plain `GameState` object, advanced by `advance(state, dtMinutes)` in steps of at most one game minute. World generation (`src/world/*`) is a seeded function of the seed. The UI (`src/ui/*`) is string-rendered panels that only re-render when their content changes, plus per-frame bar updates. `main.ts` owns the loop, save and offline catch-up.

**Tech Stack:** Vite 5, TypeScript 5, vitest 2 with happy-dom, no runtime dependencies.

**Spec:** `08-survidle/docs/superpowers/specs/2026-09-02-survidle-design.md`

## Global Constraints

- Directory `08-survidle`; `vite.config.ts` sets `base: "/prototypes/08/"`.
- `npm test` and `npm run build` pass before each commit; root `npm run lint` clean.
- Add the `<li>` to `.github/pages-index.html` in the same change.
- One scale: 1 real second = 1 game minute. All quantities in real units (km, kg, kcal, C, min).
- Map glyphs and all UI text are plain typable ASCII.
- Stage with explicit paths under `08-survidle/` and `.github/pages-index.html`.

### Task 2: rng, units, calendar, weather
Produces: `Rng`, `calendar(minute) -> {day, hour, dayOfYear, season, daylightHours, isNight}`, `ambientTemperature(cal, weather)`, `stepWeather(weather, cal, rng, dt)`.
Tests: April 1 start at 08:00; midsummer daylight about 20 h and midwinter about 5 h at 62 N; July mean warmer than January mean; precipitation chain starts and stops over a simulated month; snow accumulates below 0 C and melts above +2 C.

### Task 3: world generation
Produces: `generateWorld(seed) -> World { w, h, cells: Cell[], regions: Region[] }` with `Region { id, name, cells: number[], centroid, fractions, area km2, wood, capacities, neighbours: {id, km}[] }`, `startRegion(world)`.
Tests: deterministic per seed; every cell has a region; every region has at least one neighbour; start region forest >= 0.4; distances positive and symmetric.

### Task 4: items, inventory, animals
Produces: catalogues; `packWeight(inv)`, `addProduced(state, item, qty)` routing to pack under 25 kg else cache (logs always cache); `consume(state, needs)` from pack+cache; `dailyAnimals(state, rng)`; `densityLabel(pop, K)`.
Tests: routing; consumption across pack and cache; growth capped by K; migration conserves total population; winter thins deer.

### Task 5: player drift and death
Produces: `feltTemperature(state)`, `stepPlayer(state, dt)`, `checkDeath(state)`.
Tests: fed warm resting regenerates; zero reserve drains health at 2/h; felt below 10 lowers warmth; hypothermia drains 6/h; death cause recorded and `state.dead` set.

### Task 6: tasks
Produces: `TASKS: Record<TaskId, TaskDef>`, `availableTasks(state)`, `startTask(state, id, arg?)`, `stepTask(state, dt, rng)`, `completeTask(...)`.
Tests: chop yields to cache and reduces wood and axe; hunt success removes an animal and yields; travel moves the player after distance/speed; repeat restarts; craft consumes and produces; build persists progress and finishes.

### Task 7: camp and events
Produces: `stepCamp(state, dt, rng)` (fire burn, autoFeed, rack drying, snares daily), `hourlyEvents(state, rng)`.
Tests: fire burns 3 kg/h; autoFeed pulls firewood; rack converts 3 kg to 1 kg after 48 dry hours; snare catches with hare density; wolves only at night outside shelter.

### Task 8: advance, newGame, save
Produces: `newGame(seed)`, `advance(state, dtMinutes)`, `serialize/deserialize`, `catchUp(state, realSecondsElapsed) -> LogEntry[]`.
Tests: advance of 60 minutes in 0.1 steps and in 1 steps gives the same minute; catch-up capped at 72 h; save round-trip equality; death removes the save key.

### Task 9: UI
Produces: `renderAll(root, state, ui)`, `updateBars(state)`, map html, panels, death and away screens; `main.ts` loop with event delegation on `data-act`.
Tests: reachability - every TaskId, recipe, structure and species id appears as `data-act` in a fresh game's actions panel (with a state where all are unlocked); map renders one span per cell; clicking a travel button starts the travel task.
