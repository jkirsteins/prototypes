# Goal UX review shots

History only: goals became opportunities, and the current shots and verifier
live in `docs/opportunity-ux-shots` behind `npm run opportunity-ux`.
The verifier that took these shots checked 1440x900 desktop and 390x844 mobile layouts, explicit
goal-state wording, compact welcome copy, the water note, and the absence of
old progress chrome.

- `welcome-desktop.png`: name, date, lineage skills, and a labeled tip.
- `first-goal-desktop.png`: the first goal announcement after the welcome.
- `water-transition-desktop.png`: explicit completion and new-goal wording.
- `food-goals-desktop.png`: the parallel acquisition-method checklists.
- `food-goals-mobile.png`: the same goal group at 390 CSS pixels.

Check for clipped modal content, horizontal page overflow, repeated guidance,
or unclear completed, new, and current goal states.
