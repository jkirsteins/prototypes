# Playtest 2026-09-17

Preview build of `worktree-survidle-idle-layer`, desktop Safari. The
tester's own words, numbered; analysis and disposition beneath each.

[1] "if i click 'begin again' or any other slow button, there should be a
    activity indicator (and the button should disappear and not be
    clickable again). Right now slow buttons give no indication something
    is happening"
    - `begin-again` runs `advance()` over the death-to-landing gap
      synchronously (`landing.ts:158`). Nothing can paint during it. Needs
      to disable the button, show the loading bar, yield a frame, then run.
      `fresh()` already does this for world solves via `solving`.
    - OPEN.

[2] "there is no camp, yet no camp opportunity"
    - Heir in Gammeldalen. `site` completes once per world; nothing
      re-arms for a camp-less survivor. Card said "No current opportunity".
    - FIXED in the panel: a survivor with no camp is pointed at `site`.
      Ruling: heirs keep the world's board (not re-onboarded).

[3] Chip row: "remove these, i never asked to add a new button row"
    - REMOVED.

[4] "'drink' is a useless opportunity... inform people about how it works
    ... opportunities used as fyi. But the real second post-camp
    opportunity should be to make a fireplace"
    - Spine becomes site -> fire pit -> ... ; waiting-goals become FYIs.
    - OPEN, design change. Needs a spec amendment.

[5] Safari: "This web page was reloaded because it was using significant
    memory" - "fix this and profile"
    - Reproduced on main too (first screenshot was main). Not introduced
      by this branch, but blocks playtesting it.
    - OPEN, highest priority. Profile before touching anything.

[6] "skills can't be blocked by tech i haven't unlocked yet, and things
    where i need to wait (like water drinking) can't block reveal of
    actionable items. So all the 'just wait' things should be an fyi"
    - Also: "i have a 'blocked by knife' action but i can't make a knife"
      - a revealed row blocked by an unrevealed one, the exact failure the
      reveal tests exist to forbid. For an heir the world remembers
      `make:wedges` from an ancestor who held a knife; the heir lands
      without one. World-scoped discovery plus life-scoped kit.
    - OPEN. This is the rule for [4]: a revealed row may be blocked only by
      something revealed and actionable, or by pure waiting. Becomes a test.
