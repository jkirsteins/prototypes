Preview build of `worktree-survidle-idle-layer`, desktop Safari. The
tester's own words, numbered; analysis and disposition beneath each.

[1] "if i click 'begin again' or any other slow button, there should be a
    activity indicator (and the button should disappear and not be
    clickable again). Right now slow buttons give no indication something
    is happening"

      synchronously (`landing.ts:158`). Nothing can paint during it. Needs
      to disable the button, show the loading bar, yield a frame, then run.
      `fresh()` already does this for world solves via `solving`.
    - FIXED: beginAgain and nextBoat run behind the loading bar, which is
      shown and painted before the work starts and covers every button.
