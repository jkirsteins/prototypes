# Separate "take" Verb Implementation Plan

> **For agentic workers:** executed inline in one commit - the ink prose, verb type, and test edits are tightly coupled and must land together.

**Goal:** Add a third verb "take" to the strip so picking up the nail and tin is "take", not "use". "use" on those items stops picking them up.

**Architecture:** Ink stays the source of truth. New `take_nail` / `take_tinderbox` dispatcher handlers own pickup; `use_nail` / `use_tinderbox` become flavor-only (tool-waiting when carried, a nudge when merely spotted). `interact_fallback` gains a `take` branch. TS widens `ItemVerb` and the strip renders three verbs.

## Global Constraints

- Player-visible prose must never contain: coffin, cell, prison, dungeon, tutorial, build set, clue found, item gained, memory gained, deduction.
- Only typable ASCII punctuation.
- Mechanics stay hidden; state changes are silent.
- `npm test` recompiles ink then runs Vitest; must end green.

## Changes

### 1. `src/ink/coffin.ink` - dispatcher

After `{ verb == "use" and item == "nail": -> use_nail }` add:

```
{ verb == "take" and item == "nail": -> take_nail }
```

After `{ verb == "use" and item == "tinderbox": -> use_tinderbox }` add:

```
{ verb == "take" and item == "tinderbox": -> take_tinderbox }
```

### 2. `src/ink/coffin.ink` - nail stitches

Replace `= use_nail` (the whole stitch) with:

```
= use_nail
# image:coffin-nail
{ inventory ? nail:
    You turn the nail over in your fingers. It is waiting for something worth prying.
- else:
    The nail is still snagged in its seam. Your fingers want it in your fist first.
}
-> room_return

= take_nail
# image:coffin-nail
{ inventory ? nail:
    The nail is already in your fist, right where you want it.
- else:
    ~ spotted -= nail
    ~ inventory += nail
    You worry the nail back and forth until it gives up its tiny post. It is bent, sharp, and mean enough to matter.
}
-> room_return
```

### 3. `src/ink/coffin.ink` - tin stitches

Replace `= use_tinderbox` (the whole stitch) with:

```
= use_tinderbox
{ inventory ? tinderbox:
    You turn the tin over in your hand. It wants something worth lighting.
- else:
    The tin lies in the drawer where you found it. Better in your hand first.
}
-> room_return

= take_tinderbox
{ inventory ? tinderbox:
    The tin is already in your hand, its weight a small comfort.
- else:
    ~ spotted -= tinderbox
    ~ inventory += tinderbox
    You lift the tin out of the drawer. It has a satisfying weight, like a promise kept.
}
-> room_return
```

### 4. `src/ink/coffin.ink` - take fallback

Replace the `interact_fallback` conditional body:

```
=== interact_fallback(verb, item) ===
{ verb == "look":
    You study it a while longer. It tells you nothing new.
- verb == "take":
    You take hold of it, but it stays where it is.
- else:
    You try it this way and that, and nothing comes of it.
}
-> room_return
```

### 5. `src/ink/coffinScene.ts`

`export type ItemVerb = "look" | "use";` -> `export type ItemVerb = "look" | "use" | "take";`

### 6. `src/main.ts`

Verb render list: `(["look", "use"] as const)` -> `(["look", "use", "take"] as const)`.

Verb click handler - replace:

```ts
      selectedVerb = button.dataset.verb === "use" ? "use" : "look";
```

with:

```ts
      const verb = button.dataset.verb;
      selectedVerb = verb === "use" || verb === "take" ? verb : "look";
```

- "keeps the escape unreachable..." line 212: `take` nail.

- Tin pickups (lines 314, 360, 382, 399, 458): `take` tinderbox.

Stays `use` (tool-waiting flavor, item already carried):
- "covers the lining and nail look/use branches..." line 263 (`use` nail -> "worth prying") stays; line 257 pickup -> `take`.
- "covers the drawer, tinderbox, and candle..." line 466 (`use` tinderbox -> "worth lighting") stays; line 458 pickup -> `take`.

New tests (append inside the `describe("opening ink scene", ...)` block):

```ts
  it("does not pick up a spotted item with use, only with take", () => {
    const scene = new CoffinScene();

    interact(scene, "look", "lining");
    interact(scene, "use", "nail");

    expect(scene.snapshot.inventory).not.toContain("nail");
    expect(scene.snapshot.spotted).toContain("nail");
    expect(scene.snapshot.paragraphs.join(" ")).toContain("in your fist first");

    interact(scene, "take", "nail");
    expect(scene.snapshot.inventory).toContain("nail");
  });

  it("shrugs off taking a fixed object", () => {
    const scene = new CoffinScene();
    enterRoomByForce(scene);
    choose(scene, "Look around.");

    interact(scene, "take", "table");

    expect(scene.snapshot.spotted).toContain("table");
    expect(scene.snapshot.paragraphs.join(" ")).toContain("stays where it is");
  });

  it("flavors taking an item already in hand", () => {
    const scene = new CoffinScene();
    interact(scene, "look", "lining");
    interact(scene, "take", "nail");

    interact(scene, "take", "nail");

    expect(scene.snapshot.paragraphs.join(" ")).toContain("already in your fist");
    expect(scene.snapshot.inventory).toContain("nail");
  });
```
